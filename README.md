### 💻 SMR-OS (IN DEVELOPMENT)

A 100% open-source, fast, and lightweight Operating System built completely from scratch for modern UEFI hardware. 

### 🌟 Vision

SMR-OS is designed to be a clean, high-performance alternative to modern heavy operating systems. It cuts out all unnecessary background noise to give you direct, raw control over your computer's hardware. 

### ✨ Core Pillars

* **Zero Bloatware** – No telemetry, no hidden apps, and no background tracking.
* **100% Open Source** – Built for the community with complete transparency.
* **Modern UEFI Hardware** – Designed exclusively for modern 64-bit computers.
* **Insanely Fast** – Optimized to boot instantly and maximize your system resources.

### 🚧 Roadmap

* [x] **UEFI Boot Support** – Natively starting on real physical hardware.
* [ ] **Graphics Engine** – Turning on the screen pixels and pixels rendering.
* [ ] **The Desktop Experience** – Designing a user interface with a Start Menu.
